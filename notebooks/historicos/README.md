# Notebooks históricos

Requería `diarization.json`, `transcription.json` y `whisper_words.json` producidos según el contrato anterior; el STT integrado produce `asr.json`. No se presenta como ejecutable con el pipeline actual. Conservar sin modificaciones para trazabilidad. El análisis del contrato vigente está en [`../stt_asr_peru.ipynb`](../stt_asr_peru.ipynb). Adaptar las métricas históricas al contrato vigente es una tarea de evaluación separada, no de reorganización.
