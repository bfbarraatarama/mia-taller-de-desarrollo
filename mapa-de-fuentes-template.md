# Mapa de fuentes

**En equipo · Clase 3 · se completa en el taller y se presenta en vivo o se entrega por escrito**

## Para qué es

El mapa de fuentes es la tabla que pasa la hipótesis de datos de tu canvas a fuentes concretas, con una fila por fuente. Una fuente es el lugar concreto de donde el equipo saca un dato, como la base de clientes de una empresa, una API pública o un dataset abierto. El mapa dice de cada una a qué familia pertenece, si se puede usar hoy, qué cuesta, qué riesgos se ven antes de tener el dato, y quién la consigue y para cuándo.

Todo lo que se escribe acá es una hipótesis hasta que alguien del equipo abre la fuente.

## Cómo se completa

- Partí de la sección 5 del canvas y de su columna «¿Lo vimos?». Si esa sección está vacía, contestá primero cuál es el dato del que más depende el proyecto.
- Empezá por ese dato, y seguí con las demás fuentes.
- En «¿Está disponible hoy?» escribí quién del equipo abrió la fuente. Si nadie la abrió, es una fuente fantasma: se intenta abrir ahora, en el aula.
- Sumá las fuentes que el canvas no nombra y que se te ocurran ahora.
- Cada fuente sale con un responsable y una fecha. Sin eso, el mapa queda en una lista de deseos.
- Si sospechás que el dato del que más depende el proyecto no existe o no se puede conseguir, decilo hoy al docente.
